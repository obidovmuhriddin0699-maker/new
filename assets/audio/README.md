# Music

Background track: `assets/audio/dilbarjon.mp3` (set in `weddingData.music`).
Playback starts muted-by-default and fades in only after the guest taps "ENTER INVITATION".
To change the music, replace the file or point `music` to another file in `data/wedding.json`.
If the file is missing, the music controller stays hidden and the invitation works without sound.
